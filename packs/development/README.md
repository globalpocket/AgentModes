# Development Pack

The Development Pack is not included in the free open-source AgentModes Core distribution.

It is intended for member-only delivery through GitHub Sponsors or another private member channel. The pack provides bounded role contracts for implementation, test writing, verification review, documentation updates, and integration review.

This directory is only a Core-side placeholder. The actual Development Pack is expected to move to a separate repository as the pack is productized.

Expected role ids:

- `packs.development.requirements-analyst`
- `packs.development.implementation-worker`
- `packs.development.test-writer`
- `packs.development.verification-reviewer`
- `packs.development.documentation-updater`
- `packs.development.verified-integrator`

Brownie Runtime may load this pack when installed. AgentModes Core remains usable without it.
