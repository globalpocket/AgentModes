# AgentModes Packs

`packs/` is the extension point for role-contract packs that run on top of AgentModes Core.

The open-source Core distribution does not include full workflow packs. Packs may be published separately with their own license, access policy, versioning, installation flow, and repository.

Member-only packs can depend on AgentModes Core schemas and Brownie Runtime policies, but Core must not depend on member-only pack contents.
