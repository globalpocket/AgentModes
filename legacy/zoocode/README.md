# Legacy ZooCodeCustom/RooCode Material

This directory preserves the AgentModes v1 assets that targeted ZooCodeCustom and RooCode custom-mode operation.

The files here may contain:

- ZooCodeCustom or RooCode custom mode YAML fields.
- UI labels, emoji names, and display metadata.
- Boomerang `new_task` and `switch_mode` guidance.
- Mode-switching prose and recursive handoff instructions.
- Legacy slash-command entrypoints.
- Old completion and delegation rules that assumed the Runtime could not repeatedly invoke roles.

These files are compatibility artifacts only. AgentModes v2 core contracts must not import, reference, or depend on this directory.

The previous root README is preserved as `README.v1.md`.
